Le studio

Questions fréquentes

Avant de commencer

Une autre question ? Écrivez-moi, je vous réponds directement.

Quelle différence entre un outil interne et une application ?

Un outil interne est utilisé par votre équipe pour organiser le travail. Une application peut rendre un service à vos clients, membres ou partenaires. Un même projet peut combiner ces usages.

Comment est fixé le prix d'un projet ?

Chaque projet est réalisé sur devis, après un premier échange. La proposition précise le périmètre de la première version, le délai et le prix.

Je ne suis pas à l'aise avec la technique, est-ce un problème ?

Non. Vous m'expliquez votre activité avec vos mots, je la traduis en solution technique et je vous accompagne dans la prise en main.

Pourrai-je modifier les contenus moi-même ?

Oui, c'est prévu dès la conception : textes, paramètres ou questions peuvent être modifiés depuis une interface d'administration, selon le projet.

Où sont hébergées les données ?

L'hébergement est choisi selon la sensibilité des données. Pour les projets qui l'exigent, les données sont hébergées dans l'Union européenne.
